# Security Policy

Do not include API keys, credentials, or private session text in public GitHub issues.

PriceFlow does not ask users to paste API keys into its UI. Credentials are resolved through the DSH Host integration.

For sensitive reports, use GitHub private vulnerability reporting or Security Advisories once they are available for the public repository. If private reporting is not yet enabled, do not disclose secrets in a public issue; wait until a private contact channel is available.
